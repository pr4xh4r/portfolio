# 🪐 pr4xh4r // PORTFOLIO WEBSITE
### Modern Developer Portfolio & Interactive Terminal

A sleek, modern developer portfolio featuring an obsidian dark aesthetic with Ice Blue (`#B4D9FD`) accents, interactive canvas animations, a retro developer terminal, and clear, professional copy.

---

## 🚀 Key Highlights

1. **Clean Hero Section**:
   - **Left Column**: Clean headline (`BUILDING FAST WEBSITES & SMART APPS.`), concise bio, primary action button, contact button, and quick email copy.
   - **Right Column**: Developer card housing an interactive portrait avatar with fluid color fill effects.
2. **Interactive Avatar & Visual Effects**:
   - Toggle between Ice Blue Accent, Monochrome Dark, and Original Camera Photo.
   - Smooth wave-fill fluid animation and pixel scanline overlays.
3. **Obsidian & Ice Blue Palette**:
   - Clean dark obsidian backgrounds (`#121211`, `#171715`, `#2a2a26`) + vibrant Ice Blue (`#B4D9FD`) accents.
4. **Professional, Plain-English Copy**:
   - Written clearly for recruiters, engineering managers, and clients:
     - "Things I've Built"
     - "What I Work With"
     - "Where I've Worked"
     - "Let's Talk"

---

## 🛠️ Development & Deployment

```bash
cd portfolio

# Run dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
